Vehicle model images.

  public/images/vehicles/models/{make-slug}-{model-slug}.webp

Naming is derived from the production `vehicle` table via the same slugs the
fitment routes use, so the filename is fully predictable from the database:
  vehicle.make = "Maruti Suzuki" -> "maruti-suzuki"
  vehicle.model = "Swift"        -> "swift"

WHAT IS IN HERE
All images are transparent-background cutouts: background removed, trimmed to
the vehicle, padded uniformly, 1600px long edge, WebP. See ../SOURCES.txt for
the full per-image source, author and licence record, and
docs/vehicle-fitment-image-sources.md for the same record in prose.

Sources and licences are held in data/vehicle-fitment-image-sources.json and the
images are regenerated by:

  python scripts/prepare-vehicle-fitment-images.py

A model with no verified image is absent here on purpose. It renders a branded
placeholder carrying its own name, so an absent image is never quietly replaced
by a different vehicle.

universal-car.webp is intentionally absent: "Universal / Car" is a catalogue
grouping, not a vehicle.
